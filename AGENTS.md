# PAM Essentials working instructions

Before each new work session or major task step, read `PROJECT_STATE.md` and reconcile it with the current `main` branch.

For every requested change:
1. Break the work into chunks of about five to seven concrete steps.
2. At the start of each chunk, reread `PROJECT_STATE.md`, confirm context, and proceed only with that chunk.
3. After the chunk, update `PROJECT_STATE.md` before stopping.
4. Pause and provide a short validation checkpoint covering completed work, changed files, checks, problems, and next steps.
5. If a new requirement conflicts with a recorded decision or constraint, explain the conflict before changing direction.

The user's instructions in the active conversation take precedence. Keep the state file factual; identify historical claims that have not been reverified.
